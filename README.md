# make-knowledge-cards

将用户粘贴的文章或本地 Markdown/TXT 文件，提炼为通常 5~8 张便于复习的知识卡片。

## 项目解决什么问题

阅读文章后，重点可能分散在多个段落中，同一个观点也可能被反复表述。本 Skill 帮助筛选重要知识、合并重复内容，并将其整理为一张卡片一个知识点的学习材料，减少手动摘录和整理的工作。

这是供支持 Skills 的 AI 助手执行的文本规则，不是独立运行的应用。规则要求忠于原文，不用外部信息补齐内容；卡片的准确性仍应对照原文检查。

## 主要功能

- **文本输入**：接受粘贴的正文，或助手可读取的本地 `.md`、`.markdown`、`.txt` 文件。
- **筛选与去重**：优先提取重要定义、机制、方法、判断标准和适用条件，合并重复或同义内容。
- **按信息量生成**：通常输出 5~8 张卡片；不足 5 个独立知识点时按实际数量输出并说明原因，没有可提炼知识时不生成空卡。
- **统一结构**：每张卡片包含标题、核心知识、简明解释、原文例子或自测问题，并附简短的原文依据。
- **忠于来源**：保留数字、条件、不确定性与观点归属；原文没有合适例子时改用自测问题，不编造案例。
- **语言与输出**：默认使用原文的主要语言，在对话中输出 Markdown；可明确指定中文等其他语言，或要求保存到文件。

暂不支持网页抓取、PDF、Anki 和图形界面。只提供网址时，需要另行粘贴正文或提供支持的文本文件。本 Skill 不负责联网核实原文事实。

## 安装方法

前提：使用能够读取并执行 Skill 指令的 AI 助手。处理本地文件时，助手还需要具有相应文件的读取权限。

1. 将本项目下载或复制到本地。
2. 将 `skills/make-knowledge-cards/` 整个目录导入或复制到助手支持的 Skills 目录。具体安装路径及刷新方式以所用助手为准。
3. 保持以下目录结构，确保助手能够加载 `SKILL.md`：

```text
make-knowledge-cards/
├── SKILL.md
└── agents/
    └── openai.yaml
```

如果助手已经能访问当前项目，也可以直接要求它读取项目中的 Skill 后执行，无需复制到其他目录：

```text
请读取并使用 skills/make-knowledge-cards/SKILL.md，
将 tests/article.md 转换为知识卡片。
```

本 Skill 没有附带运行脚本，也无需安装 Python 或 npm 依赖。文末的 Python 验证命令仅供开发检查使用。

## 使用方法

完成加载后，在助手对话中调用 Skill。

### 粘贴文章

```text
使用 $make-knowledge-cards 将下面的文章整理成知识卡片：
[在这里粘贴完整正文]
```

### 读取本地文件

```text
使用 $make-knowledge-cards 将 tests/article.md 转换成知识卡片。
```

以上路径以项目根目录为基准；在其他位置使用时，请提供助手可访问的实际路径。文件不存在、不可读或乱码时，需要提供可读文本。

### 指定中文或保存文件

```text
使用 $make-knowledge-cards 将下面的英文文章整理成中文知识卡片：
[粘贴英文正文]
```

```text
使用 $make-knowledge-cards 将 tests/article.md 转换为知识卡片，
保存为项目根目录下的 knowledge-cards.md。
```

默认只在对话中输出；要求保存时由具备写文件能力的助手执行，并且不覆盖原始输入。

## 输入输出示例

以下短文只包含两个独立知识点，因此示例输出两张卡片，展示信息不足时不凑数量的行为。实际措辞可能不同。

输入：

```text
蒸发是液体表面发生的汽化，并不要求达到沸点。
液体表面积越大，蒸发通常越快。晾衣服时展开衣物可以增大表面积。
```

输出：

```markdown
原文支持 2 个独立知识点，因此生成 2 张卡片。

### 卡片 1：蒸发的含义
- **核心知识**：蒸发是液体表面发生的汽化，不要求达到沸点。
- **简明解释**：这里的汽化发生在液体表面；达到沸点不是蒸发的必要条件。
- **自测问题**：蒸发发生在哪里？是否必须达到沸点？
- **原文依据**：“蒸发是液体表面发生的汽化，并不要求达到沸点。”

### 卡片 2：表面积影响蒸发速度
- **核心知识**：液体表面积越大，蒸发通常越快。
- **简明解释**：展开衣物增大表面积，体现了这一关系在晾衣服中的应用。
- **例子**：晾衣服时展开衣物可以增大表面积。
- **原文依据**：“液体表面积越大，蒸发通常越快。晾衣服时展开衣物可以增大表面积。”
```
